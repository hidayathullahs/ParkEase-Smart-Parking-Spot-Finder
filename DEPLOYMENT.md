# 🚀 ParkEase Render Deployment Guide

This guide provides complete instructions for deploying ParkEase to **Render** using MongoDB Atlas, Docker for the Spring Boot 3 backend, and a Render Static Site for the React Vite frontend.

---

## 📋 Architecture Overview

ParkEase consists of two decoupled services defined in [`render.yaml`](file:///render.yaml):

1. **`parkease-backend`**:
   - **Type**: Web Service (Docker)
   - **Runtime**: Java 17 / Eclipse Temurin Alpine
   - **Framework**: Spring Boot 3.2.2 with Spring Data MongoDB
   - **Port**: Dynamically bound via `server.port=${PORT:5002}` and `server.address=0.0.0.0`
   - **Health Check**: `/health` (also available at `/api/health`)

2. **`parkease-frontend`**:
   - **Type**: Static Site
   - **Runtime**: Node.js build (`npm install && npm run build`), published from `dist`
   - **Framework**: React 19, Vite, Tailwind CSS, React Router, Leaflet
   - **Routing**: SPA rewrite rule (`/* -> /index.html`) to support direct navigation to `/login`, `/tickets`, `/history`, and dashboard routes.

3. **Database**:
   - **MongoDB Atlas** database cluster accessed via `MONGODB_URI`.

## 🔐 Environment Variables Summary

### Backend (`parkease-backend`)
| Variable | Description | Example / Source |
|---|---|---|
| `MONGODB_URI` | MongoDB Atlas Connection String | `mongodb+srv://<user>:<password>@cluster0.mongodb.net/parkease_db?retryWrites=true&w=majority` |
| `JWT_SECRET` | 256-bit cryptographically secure secret key | Auto-generated by Render or 64+ char random hex string |
| `FRONTEND_URL` | Deployed Frontend URL for CORS | `https://parkease-frontend.onrender.com` |
| `PORT` | Assigned dynamically by Render | Render automatically sets this (fallback `5002`) |
| `GOOGLE_CLIENT_ID` | (Optional) Google OAuth Client ID | `your-google-client-id.apps.googleusercontent.com` |

### Frontend (`parkease-frontend`)
| Variable | Description | Example / Source |
|---|---|---|
| `VITE_API_URL` | Base API URL of deployed backend | `https://parkease-backend.onrender.com/api` |
| `VITE_GOOGLE_CLIENT_ID` | Google OAuth Client ID | `your-google-client-id.apps.googleusercontent.com` |

## 🛠️ Step-by-Step Deployment Instructions

### Step 1: Set Up MongoDB Atlas
1. Log in to [MongoDB Atlas](https://www.mongodb.com/cloud/atlas).
2. Create a Free M0 cluster.
3. In **Database Access**, create a user with read/write privileges (e.g. `parkease_user`).
4. In **Network Access**, add IP `0.0.0.0/0` (Allow Access from Anywhere) so Render servers can reach the database.
5. In **Clusters** → **Connect** → **Drivers** (Java), copy your connection string:
   ```
   mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/parkease_db?retryWrites=true&w=majority
   ```

### Step 2: One-Click Blueprint Deployment via `render.yaml`
1. Push your repository to GitHub.
2. In the [Render Dashboard](https://dashboard.render.com), click **New +** → **Blueprint**.
3. Select your repository: `https://github.com/hidayathullahs/ParkEase-Smart-Parking-Spot-Finder`.
4. Render will detect [`render.yaml`](file:///render.yaml) and automatically create:
   - `parkease-backend` (Docker Web Service)
   - `parkease-frontend` (Static Site)
5. Enter the `MONGODB_URI` environment variable when prompted.
6. Click **Apply**.

---

### Alternative: Manual Service Creation on Render

#### Backend (Docker Web Service)
1. **New +** → **Web Service** → Connect your GitHub repo.
2. Settings:
   - **Name**: `parkease-backend`
   - **Region**: Choose closest to your database (e.g. `Oregon` or `Singapore`)
   - **Environment**: `Docker`
   - **Docker Context**: `./backend`
   - **Dockerfile Path**: `./backend/Dockerfile`
   - **Health Check Path**: `/health`
3. Environment Variables:
   - `MONGODB_URI`: `<your-mongodb-atlas-uri>`
   - `JWT_SECRET`: `<secure-random-key>`
   - `FRONTEND_URL`: `https://parkease-frontend.onrender.com`
4. Click **Create Web Service**.

#### Frontend (Static Site)
1. **New +** → **Static Site** → Connect your GitHub repo.
2. Settings:
   - **Name**: `parkease-frontend`
   - **Root Directory**: `frontend`
   - **Build Command**: `npm install && npm run build`
   - **Publish Directory**: `dist`
3. Redirects/Rewrites (Under **Redirects/Rewrites** tab):
   - **Type**: `Rewrite`
   - **Source**: `/*`
   - **Destination**: `/index.html`
4. Environment Variables:
   - `VITE_API_URL`: `https://parkease-backend.onrender.com/api`
   - `VITE_GOOGLE_CLIENT_ID`: `<your-google-oauth-client-id>`
5. Click **Create Static Site**.

## 🧪 Local Build & Verification Commands

### Backend Verification
```bash
cd backend
./mvnw clean test     # Runs all unit tests (7 tests passing)
./mvnw clean package  # Produces executable target/backend-0.0.1-SNAPSHOT.jar
```

### Frontend Verification
```bash
cd frontend
npm install
npm run build         # Produces production distribution in frontend/dist
```

### Docker Build Verification
```bash
cd backend
docker build -t parkease-backend:latest .
docker run -p 5002:5002 -e MONGODB_URI="<your-mongodb-uri>" parkease-backend:latest
```

## 👥 Seed Accounts
When the backend starts up, `DataInitializer` seeds default accounts if not already present:

- **Admin**: `admin@parkease.com` / `admin123`
- **Space Provider**: `owner@parkease.com` / `owner123`
- **Driver**: `user@parkease.com` / `user123`
